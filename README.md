# 우리반 단어장

학생이 첫 화면에서 지문(교과서, 모의고사 1번 …)을 골라 그 단어를 연습하는 사이트입니다. 기본으로 영어 학습지 단어 150개(1, 3-4, 5-6, 7페이지)와 유의어·반의어·파생어 44개가 들어 있고, 선생님이 단어표 사진을 올려 지문을 더 만들 수 있습니다.

- **학생:** 학번·이름·비밀번호로 처음 한 번 등록하고, 그다음부터는 학번과 비밀번호로 로그인합니다. 단어 목록 · 카드 넘기기 · 뜻 고르기 · 단어 고르기 · 철자 쓰기 · 매칭 게임으로 연습하고, **내 기록**에서 자주 틀리는 단어와 정답률을 보고 그 단어만 모아 다시 연습할 수 있습니다.
- **선생님:** 관리자 비밀번호로 들어가는 **선생님 메뉴**에서 지문을 등록하고(단어표 사진 → 자동 인식 → 확인 후 저장), **학생 기록** 화면에서 누가 언제 어떤 페이지를 몇 점으로 연습했는지, 반 전체가 많이 틀리는 단어를 보고, 학생 비밀번호를 초기화할 수 있습니다. 모든 기록은 선생님 구글 스프레드시트에도 그대로 쌓입니다.

사이트는 **GitHub Pages**에, 기록은 **선생님의 구글 스프레드시트**에 저장됩니다. 별도 서버 비용은 없습니다.

```
학생 휴대폰 ──▶ GitHub Pages (index.html)
                   │  가입·로그인·연습 결과
                   ▼
           구글 Apps Script ──▶ 구글 스프레드시트 ('학생', '지문', '모둠', '레이스', '레이스 기록' 탭)
```

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 사이트 화면과 동작 전체 |
| `config.js` | 기록 서버 주소 설정 (설치 2단계에서 한 줄 고침) |
| `words.js` | 단어 데이터 |
| `apps-script/Code.gs` | 구글 스프레드시트에 붙이는 기록 서버 코드 |
| `lib/` | QR 코드·링크 압축 라이브러리 (MIT 라이선스) |

## 설치 1단계: 구글 스프레드시트에 기록 서버 만들기 (10분)

1. 구글 드라이브에서 **새 스프레드시트**를 만들고 이름을 정합니다. (예: `단어장 학생 기록`)
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있던 코드를 모두 지우고, `apps-script/Code.gs` 파일 내용을 전부 붙여 넣습니다.
4. 맨 위 줄의 `ADMIN_PASSWORD_INIT = ''` 따옴표 안에 **관리자 비밀번호**를 적습니다.
   ```js
   const ADMIN_PASSWORD_INIT = '내가정한관리자비밀번호';
   ```
5. 💾 저장한 뒤, 위쪽 함수 선택 칸에서 **setup**을 고르고 **실행**을 누릅니다.
   - 처음엔 권한 확인 창이 뜹니다. **권한 검토 → 내 계정 선택 → 고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누르세요. 선생님이 직접 만든 코드라서 나오는 확인 절차입니다.
   - 실행 로그에 오류가 없으면 시트에 `학생`, `기록` 탭이 생깁니다.
6. 관리자 비밀번호는 이제 안전하게 저장되었으니, 4번에서 적은 비밀번호는 지우고 `''`로 되돌린 뒤 저장해도 됩니다.
7. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
   - 톱니바퀴(유형 선택)에서 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

> **학교 구글 계정(@○○.go.kr, 교육청 계정 등)을 쓸 때:** 학교 관리자가 "모든 사용자" 공개를 막아 둔 경우가 있습니다. 7번에서 "모든 사용자"가 보이지 않으면 개인 Gmail 계정으로 1단계를 다시 진행하세요.

## 설치 2단계: 서버 주소 넣기

`config.js`를 열어 복사한 주소를 붙여 넣습니다.

```js
apiUrl: "https://script.google.com/macros/s/AKfycb.../exec",
```

## 설치 3단계: GitHub에 올리기

1. GitHub에서 **+ → New repository**, 이름(예: `word-practice`)을 정하고 **Public**으로 만듭니다.
2. **uploading an existing file**을 눌러 압축을 푼 폴더 안의 파일과 폴더(`lib`, `apps-script` 포함)를 모두 끌어다 놓고 **Commit changes**를 누릅니다. `index.html`이 저장소 맨 위에 있어야 합니다.
3. **Settings → Pages**에서 Source는 **Deploy from a branch**, Branch는 **main** / **/(root)** 로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 사이트 주소가 생깁니다: `https://내아이디.github.io/word-practice/`

> ⚠️ 저장소는 공개됩니다. `Code.gs`의 `ADMIN_PASSWORD_INIT`에 비밀번호를 적은 채로 올리지 마세요. (1단계 6번처럼 지운 상태로 올리면 됩니다.)

## 쓰는 방법

### 학생 접속 주소와 QR

| 주소 | 열리는 화면 |
| --- | --- |
| `…/word-practice/` | 첫 화면 (학생이 지문을 고름) |
| `…/word-practice/#s1a2b3c4` 처럼 지문마다 생기는 주소 | 그 지문 연습 (QR 화면에서 골라 만들어요) |
| `…/word-practice/#p1` · `#p3-4` · `#p5-6` · `#p7` | 해당 학습지 페이지 연습 |
| `…/word-practice/#all` | 전체 150개 섞어서 |
| `…/word-practice/#team` | 모둠 레이스 입장 (반 → 모둠 고르기) |
| `…/word-practice/#admin` | 선생님 메뉴 (학생 기록 · 지문 관리 · 모둠 레이스 · QR) |

선생님 메뉴는 학생 화면에는 보이지 않아요. `#admin` 주소로만 들어갑니다. **QR** 탭에서 위 주소들의 QR을 만들고 PNG로 저장할 수 있습니다. 반드시 GitHub Pages 주소로 연 상태에서 만드세요.

### 지문 등록하기 (교과서, 모의고사 1번 …)

1. `#admin` → 관리자 비밀번호 → **지문 관리** 탭 → **+ 새 지문 만들기**를 누릅니다.
2. **지문 이름**을 씁니다. 예: `모의고사 1번`
3. **단어표 사진 고르기**로 사진을 올리면 10~30초 뒤 영어 단어와 뜻이 아래 칸에 들어와요. 여러 장도 됩니다.
   엑셀·구글 시트에서 단어 칸과 뜻 칸을 복사해 '단어와 뜻' 칸에 붙여 넣어도 됩니다. 번호 칸과 제목 줄은 알아서 빠져요.
4. 읽은 결과를 꼭 확인하고 고칩니다. 한 줄에 `영어 - 뜻`이고, 뜻 뒤에 `= 유의어`, `↔ 반의어 뜻`, `v) 동사 뜻`처럼 적으면 관련어도 연습에 들어가요. 사진 없이 직접 써도 돼요.
5. **저장하기**를 누르면 학생 첫 화면에 바로 나와요. 순서(↑↓), 편집, 삭제도 지문 관리에서 합니다.

지문과 단어는 구글 시트 `지문` 탭에 저장돼요. 사진은 글자를 읽는 데만 쓰고 바로 지워집니다.

### 사진 인식 켜기 (처음 한 번)

사진에서 글자를 읽는 기능은 선생님 구글 드라이브의 무료 글자 인식을 써요. 처음 한 번 켜 주세요.

1. Apps Script 편집기 왼쪽 **서비스** 옆 **+**를 누르고, 목록에서 **Drive API**를 골라 **추가**합니다.
2. 위쪽 함수 칸에서 **setup**을 골라 **실행**합니다. 권한 확인 창이 다시 뜨면 허용해 주세요. (드라이브·문서 권한이 새로 필요해서예요.)
3. **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 누릅니다.

이 설정을 안 해도 지문은 단어를 직접 써서 만들 수 있어요. 사진을 올리면 이 안내가 화면에 나옵니다.

### 모둠 레이스

반별 모둠이 한 기기로 단어 레이스를 하고 시간을 겨룹니다. 모든 설정은 `#admin` → **모둠 레이스** 탭에서 해요.

1. **반·모둠 등록:** 반 이름(예: `2학년 3반`)과 모둠을 한 줄에 하나씩 적고 저장합니다. "1~6모둠 채우기"를 누르면 빨리 넣을 수 있어요.
2. **+ 새 레이스:** 레이스 이름, 묶을 지문(예: 모의고사 1번 + 모의고사 2번, 교과서 페이지도 가능), 관련어 포함 여부, 방식, 문제 수(10·20·30·전부·직접), 틀릴 때 벌점(없음 또는 N초), 참여할 반(전체 반 또는 골라서), 보여 주기 설정을 정하고 저장합니다. 레이스 목록은 반별로 걸러 볼 수 있고, 순위판에는 "전체 반" 탭이 있어 여러 반을 한 번에 비교할 수 있어요.
   - **타임어택:** 뜻 고르기와 단어 고르기가 섞여 나오고, 맞혀야 다음 문제로 넘어가요.
   - **매칭 레이스:** 단어와 뜻 8쌍씩 여러 판을 이어서 맞혀요.
   - **철자 레이스:** 뜻을 보고 영어로 써요. 틀리면 한 글자씩 더 보이고, "건너뛰기"는 벌점이 3배예요.
   - 모든 모둠이 같은 문제를 같은 순서로 받아요.
3. 목록에서 **열기**를 누르면 그 반 모둠 화면에 레이스가 나타납니다. **마감하기**를 누르면 새로 출발할 수 없어요.
4. 모둠은 로그인 화면의 **모둠 입장** 탭(또는 `…/#team` 주소, QR 탭의 "모둠 레이스 입장" QR)에서 반 → 모둠을 골라 들어와요.
5. **순위판:** 반별 순위가 5초마다 새로 고쳐져요. "실시간 진행 중계"를 켠 레이스는 달리는 모둠의 진행 막대가 보입니다. **크게 보기 (TV)**로 교실 화면에 띄우세요.

- 모둠당 한 번만 달릴 수 있어요. 레이스 도중 틀린 답은 다시 골라 맞힐 수 있고(틀릴 때마다 벌점), 새로고침하거나 화면이 꺼져도 **이어 하기**로 계속할 수 있어요. 시간은 처음 출발한 때부터 서버가 재요.
- 기기 문제 등으로 다시 달리게 하려면 순위판에서 그 모둠의 **기록 지우기**를 두 번 누르세요.
- 기록은 구글 시트 `레이스 기록` 탭에 남아요(반, 모둠, 기록, 벌점, 틀린 단어).

### 학생 기록 보기

`…/word-practice/#admin`으로 들어가 관리자 비밀번호를 넣으면 **학생 기록** 탭이 열립니다.

- **학생별:** 학번, 이름, 연습 횟수, 정답률, 마지막 연습. 학생 줄을 누르면 그 학생이 자주 틀리는 단어와 최근 기록이 나옵니다.
- **최근 기록:** 학생마다 최근 30회씩 모아 최신순 300건을 보여 줘요. 학번이나 이름으로 찾을 수 있습니다.
- **많이 틀린 단어:** 반 전체에서 많이 틀린 단어와 틀린 학생 수.
- 기록은 구글 시트 `학생` 탭에 **학생당 한 줄**로 쌓여요. 연습 횟수, 푼 문제, 맞힌 문제, 정답률, 마지막 연습, 자주 틀린 단어가 오른쪽 칸에 보이고, 학생이 연습할 때마다 그 줄만 고쳐져요. 줄이 늘어나지 않아서 사이트가 계속 빨라요.
- 예전 방식(연습 한 번에 한 줄)으로 쌓인 기록은 setup을 실행할 때 학생 줄로 합쳐지고, 원래 탭은 `지난 기록`으로 이름이 바뀌어 그대로 남아요.

### 지난 레이스 기록 정리

`모둠 레이스` 탭 아래 **지난 레이스 기록 정리**에서 며칠 지난 레이스 기록을 `지난 레이스 기록` 탭으로 옮길지 정해요. **매일 새벽 자동으로 옮기기**를 켜면 매일 새벽 3시쯤 저절로 옮기고, **지금 옮기기**로 바로 옮길 수도 있어요. 달리는 중인 기록은 옮기지 않아요.

### 학생이 비밀번호를 잊었을 때

학생 기록 → 그 학생 줄 → **비밀번호 초기화**를 누릅니다. 학생은 **처음 등록**에서 같은 학번으로 새 비밀번호를 정하면 되고, 지난 기록은 그대로 남습니다.

### 학생 한 명을 지우고 싶을 때

구글 시트 `학생` 탭에서 그 학생의 줄을 삭제합니다. 연습 기록도 그 줄에 함께 있어서 같이 지워집니다.

### 단어 바꾸기 · 페이지 추가하기

GitHub 저장소에서 `words.js`를 열고 연필(Edit)을 눌러 고친 뒤 **Commit changes**를 누르면 1~2분 안에 반영됩니다.

```js
{
  id: "p8",                 // 주소 끝에 붙는 이름 (영문·숫자·- 만)
  t: "학습지 8페이지",        // 화면에 보이는 이름
  w: [
    ["attraction", "끌어당김, 끌림", ""],
    ["crucial", "중대한, 결정적인", "↔ trivial 사소한"]
  ]
}
```

한 단어는 `["영어", "핵심 뜻", "참고"]` 형식입니다. 참고 칸은 단어 목록과 카드 뒷면에만 보이고 퀴즈 보기·철자 문제에는 나오지 않습니다. 기존 줄을 복사해서 고치는 것이 안전합니다.

### Code.gs를 고쳤을 때

Apps Script에서 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 눌러야 반영됩니다. 이렇게 하면 웹 앱 URL은 바뀌지 않습니다.

## 설정

`config.js`

- `requireLogin: true` — 로그인해야 연습할 수 있습니다. (기본)
- `requireLogin: false` — 로그인 없이도 연습할 수 있고, 로그인한 학생의 기록만 저장됩니다.
- `apiUrl: ""` — 비워 두면 기록 기능 없이 연습만 됩니다.

## 개인정보와 보안

- 저장되는 학생 정보는 **학번, 이름, 연습 기록**뿐이며 선생님 구글 드라이브의 시트에만 있습니다. 시트를 다른 사람과 공유하지 마세요.
- 비밀번호는 원문을 저장하지 않고 해시(복원할 수 없는 형태)로만 저장합니다. 선생님도 학생 비밀번호를 볼 수 없고, 초기화만 할 수 있습니다.
- 학생 비밀번호는 **숫자 5자리**로 정합니다. 통장·카드(4자리)나 휴대폰 잠금 번호(4·6자리)와 겹치지 않게 하려는 것이고, 등록 화면에 다른 곳에서 쓰는 번호를 쓰지 말라는 경고가 보입니다. 이미 등록한 학생은 예전 비밀번호로 그대로 로그인합니다.
- 학생은 로그인 화면 아래 **비밀번호 바꾸기**에서 지금 비밀번호를 넣고 새 숫자 5자리로 바꿀 수 있습니다.
- 같은 학번으로 비밀번호를 8번 틀리면 10분 동안 로그인이 잠깁니다.
- 학생 정보를 모으기 전에 학교의 개인정보 처리 지침(수집·이용 안내 등)을 확인해 주세요.
- 공용 기기에서는 연습 후 **로그아웃**하도록 안내해 주세요.
